# УрФУ Столовая — сайт загруженности столовых ИРИТ-РТФ

Этап 1: главная страница. Три корпуса Новокольцовского кампуса УрФУ с
цветовыми индикаторами загруженности столовых.

## Возможности

- Шапка с логотипом столовой и названием, круглая кнопка «Войти как
  администратор» (в стиле логотипа) и индикатор текущей роли (Гость/Админ).
- Упрощённая схема Новокольцовского кампуса: три здания-столовые
  (ИРИТ-РТФ, ИнЭУ, ЦИМТ) с метками-пинами загруженности:
  зелёный — свободно, оранжевый — средняя, красный — высокая.
- Легенда цветов под картой.
- Клик по зданию или метке ведёт на страницу `/corpus/<id>` (пока заглушка,
  реализуется на этапе 2).
- Мобильная адаптация (mobile-first).

## Технологии

- Python 3 + Flask (Jinja2-шаблоны)
- Чистые HTML/CSS/JS, без сборщиков
- Данные о корпусах — в JSON-файле `backend/app/data/corpuses.json`

## Запуск

```bash
cd backend
python -m venv venv
venv\Scripts\activate        # Windows
pip install -r requirements.txt
python run.py
```

Откройте http://127.0.0.1:5000/ в браузере (мобильный вид — Ctrl+Shift+M).
