# УрФУ Столовая — сайт загруженности столовых ИРИТ-РТФ

Этап 1: главная страница. Три корпуса Новокольцовского кампуса УрФУ с
цветовыми индикаторами загруженности столовых.

## Возможности

- Шапка с эмблемой и названием, кнопка «Войти как администратор» и
  индикатор текущей роли (Гость/Админ).
- Три кликабельные карточки корпусов с «капельками»-пинами загруженности:
  зелёный — свободно, жёлтый — средняя, красный — высокая.
- Легенда цветов под карточками.
- Ссылки с корпусов ведут на страницу `/corpus/<id>` (пока заглушка,
  реализуется на этапе 2).
- Мобильная адаптация (mobile-first).

## Технологии

- Python 3 + Flask (Jinja2-шаблоны)
- Чистые HTML/CSS/JS, без сборщиков
- Данные о корпусах — в JSON-файле `backend/app/data/corpuses.json`

## Запуск

```bash
cd backend
python -m venv venv
venv\Scripts\activate        # Windows
pip install -r requirements.txt
python run.py
```

Откройте http://127.0.0.1:5000/ в браузере (мобильный вид — Ctrl+Shift+M).
