# УрФУ Столовая — сайт загруженности столовых ИРИТ-РТФ

Этап 2: главная страница + страницы корпусов с оценкой загруженности.
Три корпуса Новокольцовского кампуса УрФУ.

## Возможности

- Шапка с логотипом столовой и названием, кнопка «Войти как
  администратор» и индикатор текущей роли (Гость/Админ).
- Упрощённая схема Новокольцовского кампуса: три здания-столовые
  (ИРИТ-РТФ, ИнЭУ, ОЦК) с метками-пинами загруженности:
  зелёный — свободно, оранжевый — средняя, красный — высокая.
- Легенда цветов под картой.
- Страница каждого корпуса `/corpus/<id>`: расположение столовой,
  цветовая расшифровка очереди, кнопка «Меню» (заглушка этапа 3),
  форма «Оценить загруженность сейчас» (обновляется без перезагрузки).
- В админ-режиме на странице корпуса можно изменить расположение столовой —
  сохраняется в общем `backend/data/locations.json` и видно на всех страницах.
- Мобильная адаптация (mobile-first).

## Технологии

- Python 3 + Flask (Jinja2-шаблоны)
- Чистые HTML/CSS, JS для отправки оценки (`backend/static/js/main.js`)
- Данные корпусов (статичные) — в `backend/run.py`
- Текущая загруженность (`load`) — в `backend/data/load.json`
- Расположения столовых — в `backend/data/locations.json` (можно менять в
  админ-режиме)

## Маршруты

- `GET /` — главная страница.
- `GET /corpus/<id>` — страница корпуса (или 404, если не найден).
- `POST /corpus/<id>/report-load` — принимает `{"load": "low|medium|high"}`,
  обновляет `backend/data/load.json`, возвращает JSON.
- `POST /corpus/<id>/canteen-location` — (только админ) принимает
  `{"canteen_location": "..."}`, обновляет `backend/data/locations.json`,
  возвращает JSON.
- `GET /corpus/<id>/menu` — заглушка меню (реализация — этап 3).
- `POST /login` — вход администратора (JSON `{"password": "..."}`); отдельной
  страницы входа нет — пароль вводится в плашке на главной.
- `POST /logout` — выход из админ-режима.

## Запуск

```bash
cd backend
python -m venv venv
venv\Scripts\activate        # Windows
pip install -r requirements.txt
python run.py
```

Откройте http://127.0.0.1:5000/ в браузере (мобильный вид — Ctrl+Shift+M).

## Что заменить на реальные файлы позже

- Настоящие названия, адреса и этажи столовых — в списке `_CORPS` в
  `backend/run.py` (`canteen_location`).
- Пароль администратора задан в `_ADMIN_PASSWORD_HASH` в `backend/run.py`
  (хранится как hash; сменить пароль — пересчитать hash). Вход — через плашку
  на главной странице (кнопка «Войти как администратор»).
- Страница меню — этап 3 (сейчас заглушка `/corpus/<id>/menu`).
- Логика «оценки загруженности» (защита от накрутки, усреднение вместо
  перезаписи) — обсудить, не реализовано.
- Изображения лежат в `backend/static/img/`: `logo-cafe.jpg` (логотип),
  `map-nvk.png` (карта), `pin-{low,medium,high}-{irit,ineu,cimt}.png`
  (метки загруженности).
